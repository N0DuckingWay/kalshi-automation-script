| `run_lock.py` | The machine-wide lock that lets one live trading run place orders at a time: an flock on `config.LIVE_RUN_LOCK_FILE` (`~/.kalshi_betting/live_run.lock`, read at call time), shared by every checkout and worktree since they all trade one account. `acquire()` makes the folder, takes an exclusive lock, retrying every `LIVE_RUN_LOCK_POLL_SECONDS` for `LIVE_RUN_LOCK_WAIT_SECONDS`, rewrites the file with the holder's pid, checkout (`PROJECT_ROOT`) and UTC start time, and returns the descriptor (closing it releases the lock), or `None` when the lock is still held; an error making or opening the file propagates, so it never reads as `EXIT_RUN_IN_PROGRESS`. `held()` takes a shared lock and drops it at once (True when held, or when the file cannot be opened; False with no file or a free lock), so a momentary check never makes a starting run give up. `holder()` reads the record (a `LockHolder` whose fields are `None` when missing or unreadable, with `describe()` and `age_seconds()`), for messages only — whether a run may trade is decided by the flock.
